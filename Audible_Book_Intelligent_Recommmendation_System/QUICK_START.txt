STEP 1: DATA PREPROCESSING (1_data_preprocessing.py)
──────────────────────────────────────────────────

Input: 2 CSV files (6368 books)

What it does:
  ✓ Load and merge CSV files
  ✓ Remove ₹ symbols from prices
  ✓ Fill missing values
    - Rating → 3.5 (neutral)
    - Reviews → 0 (new books)
    - Price → median price
    - Description → "Unknown"
  ✓ Fix invalid values (cap rating at 5.0, fix negative prices)
  ✓ Remove duplicates (6368 → 6245 books)
  ✓ Standardize text (lowercase, remove whitespace)

Output: cleaned_data.pkl (6245 clean books)

Example:
  Before: Price = "₹499", Rating = 5.5, Reviews = NaN
  After: Price = 499.0, Rating = 5.0, Reviews = 0

───────────────────────────────────────────────────────

STEP 2: TF-IDF VECTORIZATION (2_tfidf_vectorization.py)
──────────────────────────────────────────────────────

Input: 6245 book descriptions (text)

What it does:
  ✓ Convert text to numbers
  ✓ Keep top 500 most important words
  ✓ Ignore common words (the, a, is, etc.)
  ✓ Ignore very rare words
  ✓ Calculate importance: TF-IDF = frequency × uniqueness

Output: tfidf_matrix.pkl (6245 × 500 matrix)

Example:
  Description: "Atomic Habits: Build daily habits"
  
  Important words:
    - atomic: 0.82 (very unique)
    - habits: 0.75 (very unique)
    - daily: 0.65 (somewhat unique)
  
  Ignored words:
    - the, a, build (too common)

───────────────────────────────────────────────────────

STEP 3: SIMILARITY MATRIX (3_similarity_matrix.py)
──────────────────────────────────────────────────

Input: TF-IDF matrix (6245 × 500)

What it does:
  ✓ Calculate similarity between all book pairs
  ✓ Use cosine similarity (angle between vectors)
  ✓ Result: 6245 × 6245 matrix
  ✓ Diagonal = 1.0 (book 100% similar to itself)
  ✓ Values range: 0 to 1

Output: similarity_matrix.pkl (600 MB!)

Why pickle?
  Without pickle: 40 seconds to recalculate each time ❌
  With pickle: <1 second to load ✓
  Speed improvement: 40× faster! ⚡

───────────────────────────────────────────────────────

STEP 4: K-MEANS CLUSTERING (4_kmeans_clustering.py)
───────────────────────────────────────────────────

Input: TF-IDF matrix (6245 × 500)

What it does:
  ✓ Test K=2, 3, 4, ..., 10
  ✓ For each K, train K-Means model
  ✓ Calculate inertia (cluster tightness)
  ✓ Calculate silhouette score (quality)
  ✓ Find elbow point → K=8!

Why K=8?
  1. Clear elbow point (diminishing returns after K=8)
  2. Highest silhouette score: 0.448
  3. Makes semantic sense (8 book themes)

Output: 
  ✓ kmeans_model.pkl (trained K-Means)
  ✓ books_data_with_clusters.pkl (data + cluster labels)
  ✓ elbow_method_visualization.png (graphs)

The 8 Clusters:
  0. Self-Help & Personal Development
  1. Fiction & Literature
  2. Science & Nature
  3. Business & Economics
  4. Biography & Memoir
  5. Psychology & Behavior
  6. Philosophy & Spirituality
  7. Technology & Innovation

───────────────────────────────────────────────────────

STEP 5: STREAMLIT APP (5_app.py)
────────────────────────────────

Input: All pickle files

What it does:
  ✓ Beautiful web interface
  ✓ Three recommendation algorithms:
    1. Content-based (similarity)
    2. Clustering-based (same theme)
    3. Hybrid (BEST! - combines all signals)
  ✓ Search books and get recommendations
  ✓ Show rating, reviews, price

Hybrid Formula:
  Score = 0.4×Similarity + 0.3×Rating + 0.2×Popularity + 0.1×Cluster

Example:
  Book A: Similarity=0.8, Rating=4.5, Reviews=500
  Score = 0.4×0.8 + 0.3×0.9 + 0.2×0.5 + 0.1×1.0 = 0.65
